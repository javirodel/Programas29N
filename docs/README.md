# Documentación técnica (`docs/`)

Índice de referencia de la documentación del proyecto **Programas 29N**. Los totales actualizados del corpus vigente se mantienen en `STATUS.md` y `audit/audit_result.json`.

| Archivo | Propósito |
| :--- | :--- |
| [`STATUS.md`](STATUS.md) | Estado vigente del corpus, integraciones realizadas y últimas verificaciones. |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Diseño del monolito modular Next.js, contratos entre módulos y pipeline N0–N4. |
| [`DATA_MODEL.md`](DATA_MODEL.md) | Tipos, esquemas Zod, jerarquía documental N0–N4 e invariantes del modelo. |
| [`DECISIONS.md`](DECISIONS.md) | Registro de Decisiones de Arquitectura (ADRs D-001 a D-018). |
| [`DATA_AUDIT.md`](DATA_AUDIT.md) | Metodología de auditoría inicial de los documentos y trazabilidad por hashes. |
| [`PRD.md`](PRD.md) | Requisitos funcionales y criterios de calidad editorial de partida. |
| [`PRODUCT_BRIEF.md`](PRODUCT_BRIEF.md) | Propuesta de valor, perfiles de uso y métricas editoriales. |
| [`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md) | Plan secuencial original por fases de desarrollo. |
| [`audit/audit_result.json`](audit/audit_result.json) | Resultado legible por máquina generado por `scripts/auditar_corpus.py`. |
